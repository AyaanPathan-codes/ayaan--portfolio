## ✨ Features

- ⚡ Smooth scroll animations powered by **Framer Motion**
- 🎨 3D interactive card effects with CSS perspective transforms
- 📱 Fully responsive — mobile, tablet & desktop
- 🌙 Dark luxury theme with cyan/violet gradient accents
- 💌 Working contact form with **EmailJS** + auto-reply
- 🪢 Rope-style education timeline with scroll-driven SVG animation
- 🔥 Bento grid services layout with mouse spotlight effect
- 🧠 Tech stack showcase with hover glow effects

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/AyaanPathan-codes/ayaan--portfolio.git

# Navigate into the project
cd ayaan--portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
